# IFC Viewer Scratch

A fresh Power BI custom visual scaffold for loading IFC models from URL and rendering them in 3D.

## Notes
- Uses `three`, `web-ifc`, and `web-ifc-three`.
- Uses `pbiviz` tooling from Power BI custom visuals.
- Supports selection via raycast and camera framing of the loaded model.
- Local file upload is not implemented in this scratch scaffold yet.
